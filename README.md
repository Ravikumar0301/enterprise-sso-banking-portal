# Enterprise SSO Banking Portal (Learning Project)

## Project Overview

This project is a production-style learning application that simulates an enterprise banking portal using Single Sign-On (SSO).

The goal is to learn React, Spring Boot, OAuth2/OpenID Connect, Keycloak, PingFederate, AWS deployment, Docker, and System Design step by step.

## Technology Stack

| Layer            | Technology                                   |
| ---------------- | -------------------------------------------- |
| Frontend         | React (Create React App)                     |
| Authentication   | Keycloak (POC) → PingFederate (Later)        |
| Backend          | Spring Boot (Java 21)                        |
| Database         | PostgreSQL                                   |
| Containerization | Docker                                       |
| Deployment       | AWS Route53 + ALB + Private S3 REST Endpoint |

## Learning Roadmap

* Module 00 – Docker & Keycloak Setup
* Module 01 – React Project Setup
* Module 02 – OAuth2 Login with Keycloak
* Module 03 – React Router & Case Management
* Module 04 – Spring Boot REST APIs
* Module 05 – JWT Validation
* Module 06 – Role Based Authorization
* Module 07 – PostgreSQL Integration
* Module 08 – AWS Deployment
* Module 09 – PingFederate Migration
* Module 10 – System Design
